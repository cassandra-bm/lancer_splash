2048 (PICO 8)

Click Here to Play~

This is a clone of the classic tile sliding time-waster 2048. Hashing out the game mechanics didn't take too long, but I wanted to add some polish (audio, visuals, basic scoring, etc...) to this so that I'd have a full game under my belt.

It plays pretty simply. 'Z' to start the ganme, 'X' to return to the main menu. Arrow keys to slide the pieces.

I really enjoyed writing the music for this one. I initially tried to write a fugue based on some of the melodic motiffs in Smash Mouth's All-Star (to fit with the silly Shrek reference), but I ended up going with something closer to a walz. Maybe that's a little discordant with the whole "big city vibe", but it certainly fits in with the history of puzzle games like Tetris.
